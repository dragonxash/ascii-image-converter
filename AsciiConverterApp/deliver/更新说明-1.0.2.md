# 1.0.2 更新说明

对应你反馈的两个问题：**① 选图后报 `Convert failed: open failed: ENOENT`；② 界面是英文，要中文。**

---

## 一、修 `ENOENT`

### 原因

报错全称是：

```
Convert failed: open failed: ENOENT (No such file or directory)
```

这是**向系统要图片数据流时被拒**抛出来的。

问题出在我原来的写法上——对**同一个 Uri 连开了三次流**：

| 第几次 | 干什么 |
| --- | --- |
| 1 | 只读图片尺寸（`inJustDecodeBounds`） |
| 2 | 读 EXIF 方向 |
| 3 | 真正解码出 Bitmap |

相册给的是别的应用（媒体库）的 `content://` 地址，能不能开、能开几次，**完全看对面那个 provider 的心情**。只要三次里有任何一次被拒，整张图就废了。

### 改法

**只向 provider 要一次数据**，整份复制到 App 自己的缓存目录，之后量尺寸 / 读 EXIF / 解码**全部读本地文件**。provider 再奇怪也只被打扰一次。

同时准备了几种打开方式，一种不行自动换下一种：

| 顺序 | 方式 |
| --- | --- |
| 1 | `ContentResolver.openInputStream` |
| 2 | `ContentResolver.openFileDescriptor` |
| 3 | `ContentResolver.openAssetFileDescriptor` |
| 4 | `file://` 直接读文件 |

**全失败时**，报错信息会带上 Uri 和每一种方式的失败原因，一眼能看出是哪一步卡住。

### 另加一条兜底路子

「选图」按钮现在会先问一句从哪选：

| 选项 | 说明 |
| --- | --- |
| **系统相册** | 照片选择器，能看大图、不需要权限（原来的方式） |
| **文件选择器** | 按文件夹浏览，拿到的 Uri 兼容性明显更好 |

**如果某张图在相册那条路读不出来，换文件选择器再选一次基本就好了。**
文件选择器这条路我还申请了「可持久化读权限」，所以进度不会被系统回收掉。

## 二、界面语言

你看到英文，是因为**你手机的系统语言是英文**——资源本来是中英双份、默认跟随系统的。

现在改成：**默认简体中文，不看系统语言**；右上角菜单里多了「**语言**」，可以切：

| 选项 | 效果 |
| --- | --- |
| **简体中文** | 默认，固定中文 |
| English | 固定英文 |
| 跟随系统 | 回到"系统是什么就用什么" |

底栏（选图/拍照/批量/存图片/分享）和样式设置面板都在这个范围内，全套中文。

### 附带的小改进

切换语言会让界面重建一次。为了不让你之前选的图和调好的参数白费，我加了状态保存——**重建后图片和参数会自动接回来**（前提是那张图还能读到）。
