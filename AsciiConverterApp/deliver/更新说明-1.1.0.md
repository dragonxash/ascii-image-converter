# 更新说明 · 1.1.0

**版本**：1.0.2 → 1.1.0（versionCode 3 → 4）
**包名**：`com.dragonxash.asciiconverter`（没变，可直接覆盖安装）
**体积**：1.56 MB（1.0.2 是 1.55 MB，基本持平）

这个版本把流程做成了**双向**：以前只能「图片 → 字符画」，现在字符画能原样拿出来（复制 / 存 TXT / 分享），也能再塞回去（剪贴板 / TXT 文件 → 图片）。

---

## 一、新增：文字结果面板（字符画 → 文本）

以前右上角菜单里是分开的「复制」和「存文本」两项，现在合并成一个 **「文字结果」**（菜单第一项旁边那个 `A` 图标，始终显示在工具栏上）。

点开后是一个底部弹窗：

| 部件 | 说明 |
| --- | --- |
| 正文区 | 等宽字体显示完整字符画，字号按列数自动缩放到刚好铺满宽度。可长按选中 |
| 信息行 | `网格 96×48 · 4608 字符` |
| **复制** | 整段字符画进剪贴板 |
| **存为 TXT** | 存成 `.txt` 到系统下载目录（Android 10 以下走存储权限） |
| **分享 TXT** | 通过任意 App 把 `.txt` 分享出去（走缓存 + FileProvider，不需要权限） |

同时字符画**始终跟着结果走**：导入文字生成图片后，再点这个面板拿到的也是同一段原文，可以直接改完再存。

---

## 二、新增：导入文字（文本 → 图片）

入口有两个，效果一样：

- 底栏新增 **「导入」** 按钮
- 右上角菜单 → **「导入」**

打开的面板：

| 部件 | 说明 |
| --- | --- |
| 输入框 | 等宽字体，7~14 行，直接手打或粘贴 |
| **从剪贴板粘贴** | 一键把剪贴板内容填进来（先复制好再点） |
| **打开 TXT 文件** | 从文件管理器选一个 `.txt` 读进来 |
| 信息行 | 实时显示 `网格 96×48 · 4608 字符`，边输边更新 |
| **输出宽度** | 滑块，240 ~ 2160 px，默认 1080 px |
| **清空** | 清掉输入并关面板 |
| **生成图片** | 关面板，主界面直接出图 |

生成出来的图和正常转换的结果一样，能存 PNG、分享、进样式面板重新调参数——**调参数会实时重渲染**，不用重新粘贴。

### 为什么反着来也能看

字符表是双向的：正向是「亮度 → 字符」，反向就是「字符 → 亮度」。

- 每个字符在 92 级表里的位置，反查出对应的亮度值，重建成一张灰度网格
- 表外的字符做了就近替换：`"` → `'`、`\` → `/`、`~` → `-`；中文等非 ASCII 一律当实心块（`#`）处理
- 行高按 `字宽 / textAspectRatio` 算，所以**再导出成文本、再导回来，长宽比不会越滚越歪**

我用 Python 把反向映射跑过一遍验证：92 个字符全能定位，亮度来回转换最大只差 1 级（平均 0.196 级），没有一个字符偏差超过 1 级。也就是说来回转换基本无损。

## 三、其它改动

| 项 | 变化 |
| --- | --- |
| 底栏按钮 | 从 5 个变 6 个：选图 / 拍照 / **导入** / 批量 / 存图 / 分享（「存图」文案缩短，给新按钮腾位置） |
| 右上角菜单 | 「存文本」「复制」移除，功能合并进「文字结果」面板；新增「导入」；「文字结果」用独立图标常驻工具栏 |
| 打开 TXT 的类型 | 放宽到 `text/*` + `application/octet-stream`——有些文件管理器不给 `.txt` 打标准的 text/plain |
| 读 TXT 编码 | 优先 UTF-8；如果出现替换字符（`U+FFFD`）自动改用 GBK 重读，老 Windows 记事本存的 TXT 也不会乱码 |
| 读文件通用化 | 新抽了一个统一的读取模块，图片和文本共用同一套多策略读取（直接流 → 文件描述符 → AssetFileDescriptor → file://），某条路走不通自动换下一条，报错信息里会带上 Uri 和每一条失败原因 |
| 崩溃/异常取证 | 导入流程的失败也会走原有的取证机制，「查看上次错误」能看到完整堆栈 |
| 状态保存 | 转屏/后台被杀再回来，导入的文本和输出宽度都会恢复（原文本存在缓存文件里，不塞进 Bundle，避免超大字符画触发 TransactionTooLarge） |

## 四、怎么装

直传 `ASCII图片转换器-1.1.0.apk` 到手机点击安装。

**覆盖安装即可，不用卸载**——签名密钥从头到尾没变（证书 SHA-256 `37c45131...dbb369`）。

装过 1.0.x 的话，打开后底栏会多一个「导入」按钮，右上角菜单第一项变成「文字结果」，就是更新成功了。
