## 一、导入文字后无法显示彩色

### 原因

不是「彩色」坏了，是我上一版**故意把颜色关掉了**——`importText()` 里硬写了一行
`keepImageColor = false`，理由写在注释里：文本没有原图颜色，不关掉的话字符会被画成透明黑。

结果就是：不管你选哪个风格，导入的字符画永远只有一种颜色，「彩色」和「色彩填充」滑杆完全没反应。

### 怎么修的

导出的 txt 里**只有字符，原图颜色是真丢了**，算法层面没法还原。所以改成
**按亮度合成「伪彩色」**：每个格子的亮度落到一条光谱上取色。

| 亮度 | 颜色 |
| --- | --- |
| 暗（空格、`.`） | 深紫 `#3B1F6E` |
| ↓ | 蓝 `#2D6EDE` |
| 中 | 青绿 `#24C9A8` |
| ↓ | 金黄 `#F2C230` |
| 亮（`@`、`&`） | 红 `#F2444E` |

同时把 `keepImageColor = false` 那行删了，让参数原样传下去。现在的效果：

| 选择的风格 | 导入文字后的表现 |
| --- | --- |
| 终端绿 / 深海 / 极简 / 报纸 | 单色，和以前一样（这些风格本来就不开彩色，不受影响） |
| **彩色** | **字符上光谱色，画面变成热力图那种彩色的** |
| 色彩填充滑杆 | 现在真的能调了——拖动可控制多少比例的格子着色 |

用「彩色」风格时，`色彩填充 = 65%` 意味着亮度低于 165 的 74 个字符上彩色，最亮的 18 个（`@` `&` `M` `W` 这些最密的）保持白色当高光，观感和照片转出来的彩色字符画是同一个路子。

色标我单独用脚本验过（`verify_spectrum_color.py`）：92 级亮度全覆盖、边界正确、过渡连续。

### 说清楚一件事

**这不是原图颜色，是按亮度算出来的伪彩。** txt 里存不下颜色，这是信息层面的丢失，改不了。
想要真正的原图颜色，得从原图重新转一次，别走 txt 这条路。

## 二、选了中文还是英文

这是**两个 bug 撞一起**，所以之前怎么点都没反应。

### Bug 1：点「中文」被判定成「没变化」，直接跳过

```kotlin
// 1.1.0 的代码
if (picked != AppLanguage.load(this)) {   // ← 这里
    AppLanguage.save(this, picked)
    toast(...)
}
```

存储值默认就是中文。当存储值是中文、界面却是英文时，你点「中文」→
`picked == load()` 成立 → **整个分支被跳过，不保存、不应用、连提示都没有**。

看起来就像点了没反应。已删掉这个短路判断，现在每次点都保存并应用，都会给提示。

### Bug 2：界面语言本来就没真正切过去

1.1.0 只用了 `AppCompatDelegate.setApplicationLocales()` 这一条路。
它在部分系统版本 / ROM 上会**静默失效**——不报错、不抛异常，界面语言就一直跟着系统走。
所以默认语言虽然写的是中文，界面还是英文。

现在改成**两条腿走路**：

| 路径 | 作用 |
| --- | --- |
| `AppCompatDelegate.setApplicationLocales()` | 系统集成，让应用出现在「设置 → 应用 → 语言」里（包 `runCatching`，它挂掉不影响 App） |
| **`BaseActivity.attachBaseContext()` 自己改 Configuration** | **保底。**跟系统版本无关，一定能生效 |

所有 Activity 现在都继承 `BaseActivity`，创建时自动套上你选的语言。切语言后如果系统那条路没重建界面，代码会补一刀 `recreate()`（带防重判断，不会闪两次）。

### 顺手加的自检

「关于」对话框现在多两行：

```
设置的语言：简体中文
界面实际语言：zh-CN
```

以后再遇到语言不对，看这两行就能立刻判断是**存储不对**还是**没生效**，不用猜。

**没做真机测试**——构建环境里没有安卓设备也没有模拟器。特别是**语言这块，只有真机能确认**：
系统 per-app language 的行为跟 ROM 强相关，我在代码层面做了保底，但没法替你验证。

装上后麻烦看一眼：

1. 打开 App 是不是中文（默认就该是中文，不管系统语言）
2. 菜单 → 语言 → 点 English，界面是否变英文；再点回简体中文，是否变回来
3. 关于对话框里那两行语言显示是否一致

第 3 步如果「设置的语言」和「界面实际语言」对不上，把截图发我。

**彩色**那条就试着导入一段字符画，点「彩色」风格，应该能看到颜色。
如果只有部分格子有色、亮的格子是白的——那是正常的，白色是「色彩填充」阈值之外的高光部分，把滑杆拉满就全上色了。
